## 📖 Что такое G-Core?

**G-Core** — общая библиотека (зависимость) для авторских Minecraft-плагинов экосистемы **GMCPlugins**, созданной **gortex**.

Она используется плагинами GMCPlugins как обязательный компонент. Благодаря общей библиотеке плагины могут опираться на единое ядро вместо того, чтобы включать его отдельно в каждый проект.

> [!IMPORTANT]
> **Без G-Core ни один плагин GMCPlugins не будет работать.** Установите совместимую версию библиотеки перед запуском плагинов.

## ⚙️ Установка

1. Найдите актуальную версию **G-Core** в этом репозитории (раздел **Releases**, если доступен) или на [официальном сайте](https://gortex.xyz/gmcplugins).
2. Проверьте совместимость версии G-Core с выбранными плагинами и сервером Minecraft.
3. Поместите файл библиотеки `.jar` в папку `plugins/` вашего сервера, если сборка распространяется как серверный плагин.
4. Добавьте `.jar` нужных плагинов **GMCPlugins** в ту же папку.
5. Перезапустите сервер и убедитесь по логам, что **G-Core** и остальные плагины загрузились без ошибок.

> [!NOTE]
> Точные требования к серверному ПО, версии Minecraft и Java, а также инструкции по установке указываются в документации соответствующих релизов.

## ❓ Частые вопросы

**Можно ли запускать плагины GMCPlugins без G-Core?**  
Нет. G-Core — обязательная зависимость для каждого плагина GMCPlugins.

**Нужно ли устанавливать G-Core отдельно для каждого плагина?**  
Нет. На одном сервере используется общая установленная библиотека G-Core, если версии плагинов совместимы с ней.

**Где скачивать обновления?**  
В репозиториях соответствующих проектов и на [gortex.xyz/gmcplugins](https://gortex.xyz/gmcplugins).
